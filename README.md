# 大鱼吃小鱼 · 深海狂欢 (Big Fish Eat Small Fish)

一个纯 Canvas 2D 打造的大鱼吃小鱼游戏：所有美术（多品种鱼、海底、水母、河豚、鲨鱼、道具、粒子）都是程序化绘制，没有任何图片/模型资源。

> 项目最初做过 3D 版（Three.js），但第三人称视角下深度难以判断、很难咬中猎物，于是回归经典 2D 玩法并全面升级了美术与机制。

## 玩法

- **移动鼠标**：小鱼跟着游（触屏则跟随手指）
- **按住左键 / Shift**：持续加速
- **空格 / 右键**：瞬间冲刺扑向猎物（有冷却，双指点按也可）
- **M**：静音

### 核心规则

- 吃掉比自己小的鱼成长，共 6 个进化阶段：小鱼苗 → 机灵小鱼 → 浅海猎手 → 大块头 → 深海霸主 → **海洋之王**（获胜，可继续无尽模式）
- 被更大的鱼咬到会损失一颗心（共 3 条命），升级可回复
- 连续吞食触发**连击倍数**，连击 6 次进入 🔥 **狂热时刻**：双倍分数、成长加速

### 惊喜要素

- ✨ **黄金鱼**：限时出现，速度飞快，吃到成长与分数 ×5
- 🐡 **河豚**：靠近会鼓刺，被扎会眩晕掉连击；等它泄气再下口，是一顿大餐
- 🪼 **水母**：碰到会被蜇晕并缩水，绕着走
- 🦈 **巨齿鲨**：中期随机来袭（有警报），转弯慢——侧向躲避！长大后可以反过来吞掉它（+2000 分）
- 三种道具泡泡：⭐ **无敌**（大鱼都怕你）、🧲 **磁铁**（小鱼自动上门）、⚡ **狂暴**（极速 + 冲刺无冷却 + 双倍分数）
- 右下角小地图：红点 = 危险，金点 = 黄金鱼，蓝点 = 道具

## 开发

```bash
npm install
npm run dev      # 打开终端提示的地址（默认 http://localhost:5173/）
npm run build    # 生产构建
npm run preview  # 预览生产构建
```

## 技术栈

- 原生 Canvas 2D + [Vite](https://vitejs.dev/)，零运行时依赖
- WebAudio 程序化音效（无音频文件）
- 纯前端，无后端逻辑

## 项目结构

```
src/
  game/
    Game.js         主循环、相机、生成/吞食/连击/道具/鲨鱼事件、小地图
    Entities.js     玩家鱼、AI 鱼、河豚、水母、鲨鱼、道具实体与行为
    FishArt.js      程序化鱼绘制（品种、摆尾、花纹、河豚/水母/道具图标）
    Background.js   海水渐变、光柱、视差远景、沙底/岩石/珊瑚/海草/气泡
    Particles.js    气泡、吞食爆裂、金光、涟漪、飘分文字
    Input.js        鼠标/触屏/键盘输入
    Sfx.js          WebAudio 程序化音效
    UI.js           界面与 HUD
  main.js
```
